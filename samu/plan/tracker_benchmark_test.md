## ⚠️ 5. 한계점 (Limitations)

### 5.1 기술적 한계

| 한계 | 설명 | 영향도 | 완화 방법 |
|------|------|--------|----------|
| **비슷한 체형 혼동** | 쌍둥이, 유사 체형 구분 어려움 | 🔴 높음 | Appearance embedding 추가 |
| **포즈 급변** | 앉기↔서기 전환 시 매칭 실패 | 🟡 중간 | pose_history_size 증가 |
| **장시간 가림** | 90프레임(3초) 초과 시 복구 불가 | 🟡 중간 | max_missing_frames 증가 |
| **빠른 움직임** | 블러로 키포인트 부정확 | 🟡 중간 | confidence 가중치 조정 |
| **다수 인원** | 10명+ 시 매칭 복잡도 증가 | 🟡 중간 | 위치 기반 필터링 |

### 5.2 환경적 한계

| 한계 | 설명 | 영향도 | 완화 방법 |
|------|------|--------|----------|
| **조명 변화** | 급격한 조명 변화 시 키포인트 불안정 | 🟡 중간 | 히스토리 평균화 |
| **카메라 각도** | 측면/후면 뷰에서 키포인트 제한 | 🔴 높음 | 3D 포즈 추정 필요 |
| **해상도** | 저해상도 영상에서 정확도 저하 | 🟡 중간 | 고해상도 입력 |
| **군중 밀집** | 심한 가림으로 키포인트 부족 | 🔴 높음 | 상체 키포인트 우선 |

### 5.3 성능 한계

| 한계 | 현재 상태 | 목표 | 개선 방향 |
|------|----------|------|----------|
| **FPS** | ~28 fps | 30+ fps | TensorRT 최적화 |
| **메모리** | ~1.5 GB | ~1.2 GB | 이력 관리 최적화 |
| **최대 인원** | ~15명 | 30명+ | 매칭 알고리즘 개선 |
| **복구 시간** | 3초 | 5초+ | max_missing_frames 조정 |

### 5.4 알려진 실패 사례

```
실패 사례 1: 비슷한 옷을 입은 두 사람
- 상황: 같은 유니폼을 입은 직원 2명
- 결과: 체형이 비슷하면 ID 스왑 발생
- 원인: 포즈만으로는 구분 불가

실패 사례 2: 급격한 자세 변화
- 상황: 서있다가 갑자기 앉음
- 결과: 새 ID로 인식됨
- 원인: 정규화된 포즈가 크게 변함

실패 사례 3: 4초 이상 완전 가림
- 상황: 기둥 뒤로 완전히 숨었다가 나옴
- 결과: 새 ID로 인식됨
- 원인: max_missing_frames(90) 초과
```
