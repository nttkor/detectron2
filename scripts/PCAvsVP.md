3D 시각화 코드 비교 분석: PCA vs. 소실점(VP)

구분

PCA 기반 3D 객체 자세 추정 (소실점 적용 前)

소실점 기반 3D 프리미티브 드로잉 (최신 버전)

핵심 목표

객체의 **3D 공간적 자세(Pose)**와 **크기(Size)**를 정량적으로 추정 및 시각화.

이미지의 깊이감과 구조를 소실점 기반의 투시 원근법을 이용해 직관적으로 강조.

3D 로직

주성분 분석(PCA) 기반

소실점(Vanishing Point) 기하학 기반

주요 입력

Segmentation Mask, Depth Map (깊이 정보), 카메라 행렬(K)

Segmentation Mask, 직선 검출 결과, Depth Map (보조적 사용)

처리 단계

1. 2D → 3D (Back-Projection)

1. 직선 검출 및 소실점 추정



2. 3D 포인트 클라우드에 PCA 적용 (방향/크기 결정)

2. 객체 타입에 따른 프리미티브(Cube, Cylinder 등) 결정



3. 3D 큐브를 2D로 투영 (Projection)

3. 소실점을 향하는 큐브 모서리 계산 및 투영

시각화 스타일

각 객체에 대해 추정된 3D 방향에 맞춰 회전된 큐브 바운딩 박스를 그림.

객체 유형에 따라 투시 원근법이 적용된 와이어프레임 또는 구조적 선을 그림.

결과물의 정량성

높음. (Centroid, Rotation Matrix, Size Factors 등 정량적 3D 정보 출력)

낮음. (시각적 효과와 구조적 강조에 중점, 정량적 Pose 정보는 없음)

주요 단점

- Depth Map의 품질에 매우 민감함.

- 소실점 검출이 실패하거나 객체가 원통형/자유형인 경우 효과가 제한적임.



- 적절한 카메라 파라미터(K) 설정이 필요함.

- 객체의 실제 3D 자세를 정확히 반영하지 못할 수 있음.

1. PCA 기반 3D 객체 자세 추정 코드 (소실점 적용 前)

이 코드는 컴퓨터 비전의 전통적인 기법을 사용하여 객체의 3D 구조를 재구성하려는 시도입니다.

A. 핵심 개념: Back-Projection과 PCA

Back-Projection (역투영): 깊이 지도(Depth Map)와 가상의 카메라 내부 파라미터(K)를 사용하여 2D 픽셀을 3D 공간상의 점(포인트 클라우드)으로 변환합니다. back_project_points 함수가 이 역할을 합니다.

PCA: 3D 포인트 클라우드에 주성분 분석을 적용하여 객체의 형태를 가장 잘 설명하는 주축 3개(길이, 너비, 높이)와 중심점을 찾습니다. compute_pca_orientation 함수를 통해 객체의 회전 행렬과 크기를 얻습니다.

Projection (투영): 추정된 회전 행렬과 크기로 정의된 3D 큐브를 다시 2D 이미지 평면에 투영하여 포즈를 시각화합니다.

B. 장점

정량적 3D 추정: 객체의 실제 공간상의 위치, 방향, 크기를 수학적으로 추정하려는 시도입니다.

객체 중심적: 각 객체의 포인트 클라우드에 독립적으로 작용하므로, 이미지 전체의 구조에 덜 의존합니다.

C. 단점

민감도: MiDaS와 같은 단안 깊이 추정 모델은 상대적 깊이만 제공하므로, 실제 스케일이 부정확할 수 있습니다. 부정확한 깊이 정보는 PCA 결과(자세와 크기)를 크게 왜곡시킬 수 있습니다.

카메라 파라미터 의존성: FOCAL_LENGTH와 같은 가상의 카메라 내부 파라미터(K) 설정에 따라 투영 결과가 달라지며, 실제 이미지와 맞추기 어렵습니다.

2. 소실점 기반 3D 프리미티브 드로잉 코드 (최신 버전)

이 코드는 **시각적 예술과 디자인의 원리(투시 원근법)**를 활용하여 이미지의 구조를 강조하는 것에 중점을 둡니다.

A. 핵심 개념: VP 기하학 및 마스크 제약

VP Detection: VanishingPointDetector 클래스가 이미지 내의 주요 직선들을 분석하여 가장 지배적인 소실점(VP)을 찾습니다. VP는 이미지의 주된 깊이 방향을 정의합니다.

Primitive Mapping: 객체 클래스 이름(bed, table, building 등)을 분석하여 해당 객체를 **어떤 기본 3D 형상(프리미티브)**으로 모델링할지 결정합니다.

Perspective Drawing: 큐브형 객체의 경우, 2D 바운딩 박스의 모서리에서 검출된 소실점(VP)을 향해 선을 그려 인공적인 원근감을 부여합니다.

Mask Constraint (마스크 제약): 가장 중요한 특징으로, 모든 선은 객체의 segment_mask 내부에만 그려지도록 파편화(fragmentation)됩니다 (draw_line_in_mask 함수). 이는 선이 객체의 표면을 따라가도록 하여 2D 드로잉을 3D 구조처럼 보이게 합니다.

B. 장점

강력한 시각적 효과: 소실점은 인지된 깊이감을 가장 잘 표현하는 요소이므로, 결과물이 매우 구조적이고 인상적으로 보입니다.

노이즈 내성: 3D 포인트 클라우드 자체의 미세한 노이즈에 민감하지 않고, 2D 직선 정보에만 의존하므로 안정성이 높습니다.

마스크 기반의 사실적인 드로잉: 와이어프레임이 객체의 윤곽을 벗어나지 않게 제약하여 시각적 일관성을 유지합니다.

C. 단점

VP 의존성: 이미지 내에 뚜렷한 직선 구조가 없거나, 카메라가 VP가 생기지 않는 곳(예: 정면샷)을 바라볼 경우 효과가 떨어집니다.

단순화: 추정된 큐브 자세는 VP에 의해 결정되므로, 객체의 복잡하거나 특이한 3D 자세는 표현할 수 없습니다.

3. 결론 및 코드 채택 배경

두 코드는 정량적인 자세 추정에서 시각적 구조 강조로의 명확한 아키텍처 전환을 보여줍니다.

PCA 코드: 학술적이고 정량적인 접근 방식입니다. 3D 재구성과 Pose 추정에 관심이 있다면 이 코드가 적합하지만, MiDaS 깊이의 상대성 때문에 결과가 불안정하고 파라미터 튜닝이 어렵습니다.

VP 코드 (채택된 버전): 실용적이고 시각적인 접근 방식입니다. **"이미지의 구조적 깊이감을 효과적으로 보여준다"**는 목표에는 VP 기반의 투시 원근법과 마스크 제약이 훨씬 강력하고 안정적인 결과를 제공합니다.

따라서, 사용자에게 가장 인상적이고 안정적인 시각화 결과를 제공하기 위해 PCA를 대체하여 소실점 기반 Primitive Drawing 로직이 채택되었다고 볼 수 있습니다.
